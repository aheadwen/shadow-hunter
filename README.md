公开共享仓库，欢迎通过 Fork 和 Pull Request 提交贡献。

纽约上东区，初秋。驱魔师家族的少年 Ash Corbin 带着渡鸦 Bean 转学到 Hawthorne 中学，撞上了橄榄球队的“校霸” Houndson。隔壁三楼那扇封住的窗户后面，Houndson 的表妹 Lily 已经不再是她自己。

## AI 剧规格

- 横屏 16:9，一幕改编成一集。
- 画面基调是偏冷的清晨：饱和度略低，暗部更深，色调中性偏暖。只在发丝和渡鸦羽毛的边缘留一线金光。
- 对白用美式英语配音，配中文字幕。
- 制作流程：GPT 生成分镜首帧和尾帧，用 Grok 或 ComfyUI 的 MiniMax H3 生成视频，在剪映里剪辑、配音、加字幕。

## 关于版本

- **第一至八幕**：取自 Word 正文。第五幕、第七幕补入了作者后来加的“翻花绳”伏笔：第五幕是守夜那晚 Ash 教 Houndson 翻花绳，第七幕是奶奶用妈妈的红线教九岁的 Ash。
- **第一幕**：取自作者 2026-10-06 重新贴出的版本。
- **第九、十幕**：取自定稿时的对话记录，包含第九幕改定的结尾，以及恶魔化成流沙那一段。
- 作者 Mac 上的 Word 定稿如果有之后的改动，以 Word 为准。
- 设定集没有收录原文件最后的“协作偏好”一节，那是写给 AI 助手的工作备注，不属于作品内容。
- `ComfyUI-生成清单.md` 里的命令写的是 `prompts\` 目录，对应本仓库的 `ComfyUI-MiniMax-H3/` 目录；图片素材没有上传。
